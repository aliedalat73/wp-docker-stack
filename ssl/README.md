# SSL Certificates Directory

Place your SSL certificate files in this directory before starting the stack:

- `cert.pem`: Fullchain SSL certificate
- `key.pem`: SSL private key

---

## فارسی
فایل‌های گواهی SSL خود را با نام‌های زیر درون این پوشه قرار دهید:
- `cert.pem`: گواهی اصلی دامنه (Fullchain)
- `key.pem`: کلید خصوصی دامنه
